# Reviewed map-link discovery

The installed worker can dispatch a `discover_map` job through `crawl_runtime.run_map_discovery`. Activation is independently disabled by default. No retailer requests were executed while implementing or testing this path; tests inject synthetic transports.

Operator configuration must enable `network.crawl_enabled`, `crawler.enabled`, the `woodmans_maps` entry in `crawler.adapters_enabled`, and `crawler.adapters.woodmans_maps.enabled`. The adapter requires explicit `source_authorized`, `terms_reviewed` and `robots_reviewed` flags, an identifying `crawler.operator_contact`, an exact `allowed_host`, a bounded `scope_prefix`, and `approved_targets` entries containing `url`, an existing canonical `store_id`, and branch name/address evidence in `expected_branch`. Review source terms and map reuse separately before setting any approval. Offline mode and a paused or rights-blocked source remain blocked.

Use the CLI's network-free crawl plan before any later operator activation. API read keys cannot enqueue discovery or change permissions. The worker checks the live lease and source kill switch during requests, waits, parsing and publication. Only registered branch HTML pages are fetched. Central transport enforces the exact HTTPS origin, public-address DNS pinning, zero redirects, no authenticated session, and a 2 MiB page cap. Robots requests count against request budgets. Limits are at most 50 requests per run and 500 per day, with at least five seconds between requests or the stricter robots delay/rate. A discovery run is bounded to 300 seconds by default, with a 900-second maximum.

Robots text is fetched from the approved host, parsed without executing anything, and cached at most one hour by default and 24 hours maximum. HTTP `max-age` can shorten that lifetime; `no-store`/`no-cache` suppress persistence. A source raw-storage denial also suppresses and removes its robots cache. Robots errors, including 403, fail closed before branch fetches. Branch content must be HTML; a PDF response is rejected before reading its body.

Discovered map links retain branch evidence and persistent IDs allocated from source keys derived from branch URL plus map URL. Ambiguous association stays ambiguous. A page with no candidate records `not_found`; a failed or blocked run preserves the last published catalog. Results publish through the normal fenced immutable-generation path. Every discovered map has pending rights, `storage_permitted=false`, `display_permitted=false` and no assets. Discovery never fetches a linked PDF/image, renders a document, guesses aisle coordinates or rehosts map bytes. Those actions require separate rights and implementation support.
