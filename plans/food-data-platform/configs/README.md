# Planning configurations

These files are proposed contracts, not active configuration for the present repository. `production.example.json` describes the post-implementation runtime, not permission for this coding session. `development-offline.example.json` is the implementation/CI network policy. Source descriptors and crawler leads contain no live store/product data and do not seed records.

`field-refresh-policy.json` and `refresh-policy.example.json` are identical copies for convenient reference; choose one canonical runtime filename in implementation. Monetary fields in source metadata distinguish source fees from hosting; they are not quotes for commercial API access. Runtime must revalidate effective source permissions and exact redirect hosts.

`compose.proposed.yaml` is a deployment example only after the new roles/configuration exist. `ENVIRONMENT.md` explains compatibility and secret handling. No script in this package downloads, crawls, installs, deploys or imports these files.
